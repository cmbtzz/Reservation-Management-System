# 校园自习室预约管理系统界面原型

直接双击 `index.html` 即可在浏览器中打开。原型不依赖后端服务，也不需要安装额外依赖。

## 页面入口

- `index.html`：角色入口和项目视觉封面。
- `student.html`：学生端，包含找座、预约、签到与个人中心。
- `admin.html`：管理端，包含数据概览、预约管理、场地座位、违约处理和使用统计。

## 可交互操作

- 点击侧边栏或移动端底部导航切换页面。
- 在座位平面图中选择空闲座位，预约摘要会同步更新。
- 点击“确认预约”查看成功反馈。
- 在签到页输入 `386204`，可触发签到成功状态。
- 管理端可点击“处理”更新违约记录状态，并查看操作反馈。
- 管理端可复制当前签到码。

## 兼容性

原型在 Microsoft Edge 1440 × 1000 桌面视口和 390 × 844 移动视口中验证通过，无横向页面溢出。页面使用本地 CSS 和少量原生 JavaScript，不需要联网加载资源。
